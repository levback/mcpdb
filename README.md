# mcpdb

`mcpdb` is a Python package scaffold for a Model Context Protocol database server.

## Status

This repository is in the scaffolding phase. Runtime database features, MCP transport support,
and security policies will be added in later phases.

## Tooling

- `uv` for dependency management and lockfiles
- `ruff`, `mypy`, and `bandit` for quality gates
- `pytest` with branch coverage enforcement
- `pre-commit` and GitHub Actions for local and CI gating

## Quickstart

Phase 11 will add full examples and developer documentation.
